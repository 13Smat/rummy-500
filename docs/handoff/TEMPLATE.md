# Handoff

Copy this file, rename the copy with the date and a short topic, and fill it in at the end of a session. Delete the prompts in the copy.

- Date.
- Branch and pull request.
- What landed. Name the behavior a player or a later agent can use.
- What is not done. Name the ticket that owns it.
- How to check. Commands and the result you saw.
- Open questions. Point at the file. Do not answer them here if Andy has not.
