# Handoff

- Date. 2026-11-10.
- Branch and pull request. `cursor/melds-layoffs-4798`.
- What landed. `Meld.layDown` and `Meld.layOff` accept a set of 3 or 4 and a suited run of 3 or more. Ace, 2, 3 and queen, king, ace are legal. King, ace, 2, a mixed suit, and five of a kind are `MeldRejection` values. Each card keeps the `Seat` that played it. `cards(playedBy:)` returns that seat's cards from one meld. Flatten several melds with `flatMap`. A hand is still `Hand.cards`. A debug build lists `Meld.largestGroups` under each dealt hand. Seed 0 shows no meld for you and the 5, 6, 7, and 8 of clubs for the computer.
- What is not done. Turns and drawing. Scoring is already on main, and this branch keeps that debug panel. The computer opponent. Signing and TestFlight wait for the Apple ticket.
- How to check. `./scripts/check.sh` on Linux. On 2026-11-10 it passed the project file check, the rules check, and 39 engine tests. On a Mac, `xcodegen generate`, then run the Rummy500 scheme in an iPhone simulator as a debug build. Enter a seed and press Deal.
