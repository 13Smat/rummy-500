# Handoff

- Date. 2026-11-10.
- Branch and pull request. `cursor/turns-and-discard-picks-494b`. The pull request number is in the PR for this branch.
- What landed. `HandState` plays a turn. Draw the top of the stock, or take a discard and every card above it. The chosen discard has to be melded or laid off before any other move. A refusal returns `TurnRejection` and leaves the value as it was. Going out, including by discarding the last card, ends the hand with no further discard. An empty stock still allows a discard that can be used at once. Declining the pile then ends the hand. `handResult` builds a `HandResult` for `Match.record`. A debug build steps through `HandState.scriptedPlay`. The choice is `docs/adr/0007-turns-and-discard-picks.md`. The checked chart is `docs/statechart/chart.mmd`.
- What is not done. The computer opponent. The table UI that calls this engine. Signing and TestFlight wait for the Apple ticket.
- How to check. `./scripts/check.sh` on Linux. On 2026-11-10 it passed the project file check, the rules check, and 68 engine tests. On a Mac, `xcodegen generate`, then run the Rummy500 scheme in an iPhone simulator as a debug build. Under the sample score, press Next on the scripted hand. The stock, the spread discard, both hands, the table, and whose turn it is change on each press. The last step shows the hand scores.
- Open questions. `docs/RULES.md`, under Open questions. They are unanswered. This change uses the ticket defaults for an empty stock, a discard that cannot be used, going out on a discard, and which cards sit above the one you take. It does not write those answers into the rules sheet.
- State chart. The model counts cards, up to 3 in a hand and 2 in the pile. It does not name ranks or suits, and it does not score. A pile of 2 cannot take another ordinary discard, so that line melds out or discards the last card. A refused take does not change the hand, so the chart does not draw it. The chart also hides the idle step once the hand is over, and a meld that leaves the same box on the screen. TLC checked 24 states. Regenerate with a new `--out` folder.
